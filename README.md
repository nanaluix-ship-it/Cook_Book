# Кулинарная книга: расчёт продуктов

Проект реализует простую систему загрузки рецептов из текстового файла и расчёта списка покупок под количество персон.

## Функционал

- Загрузка рецептов из `recipe.txt`.
- Расчёт количества ингредиентов для заданного числа людей.
- Проверка наличия блюда в книге (выбрасывает `ValueError`, если блюдо не найдено).
